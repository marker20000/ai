# Спецификация признаков (общий контракт Python <-> Java)

Этот файл — единственный источник правды о том, что подаётся на вход сети и
что сеть предсказывает. Реализации на Python (обучение) и Java (инференс)
обязаны совпадать **побитово по индексам**. Любое изменение здесь должно
менять `pvp_bot/config.py` и `StateVector.java` синхронно.

## Нормализация (глобальные константы)

```
MAX_DIST    = 8.0    # блоков; дистанции > обрезаются до 1.0
MAX_SPEED   = 0.35   # блоков/тик; горизонтальная скорость (бег ~0.28, спринт ~0.4)
MAX_YAW_RT  = 22.5   # градусов/тик — предел поворота камеры бота
MAX_HP      = 20.0
MAX_ARMOR   = 20.0
```

## Входной вектор на один тик (27 признаков)

Индексы 0..26, в этом порядке:

| idx | имя            | описание                              | нормализация                     |
|-----|----------------|---------------------------------------|----------------------------------|
| 0   | dx             | относ. позиция врага X                | dx / MAX_DIST, clip [-1,1]       |
| 1   | dy             | относ. позиция врага Y (верт.)        | dy / MAX_DIST, clip [-1,1]       |
| 2   | dz             | относ. позиция врага Z                | dz / MAX_DIST, clip [-1,1]       |
| 3   | vx             | относ. скорость врага X               | vx / MAX_SPEED, clip [-1,1]      |
| 4   | vy             | относ. скорость врага Y               | vy / MAX_SPEED, clip [-1,1]      |
| 5   | vz             | относ. скорость врага Z               | vz / MAX_SPEED, clip [-1,1]      |
| 6   | dist           | дистанция до врага                    | dist / MAX_DIST, clip [0,1]      |
| 7   | yaw_diff       | разница yaw (враг - бот)              | yaw_diff / 180, clip [-1,1]      |
| 8   | pitch_diff     | разница pitch (враг - бот)            | pitch_diff / 90, clip [-1,1]     |
| 9   | fwd_speed      | скорость вперёд бота                  | fwd / MAX_SPEED, clip [-1,1]     |
| 10  | strafe_speed   | скорость страйф бота                  | strafe / MAX_SPEED, clip [-1,1]  |
| 11  | yaw            | абс. yaw камеры бота                  | yaw / 180, clip [-1,1]           |
| 12  | pitch          | абс. pitch камеры бота                | pitch / 90, clip [-1,1]          |
| 13  | yaw_rate       | производная yaw за тик                | yaw_rate / MAX_YAW_RT, clip[-1,1]|
| 14  | pitch_rate     | производная pitch за тик              | pitch_rate / MAX_YAW_RT, clip[-1,1]|
| 15  | weapon_cd      | кулдаун оружия                        | 0..1 (1 — готово)                |
| 16  | w_sword        | one-hot: меч                         | 0/1                              |
| 17  | w_axe          | one-hot: топор                        | 0/1                              |
| 18  | w_hand         | one-hot: рука                         | 0/1                              |
| 19  | crit           | флаг крита (в воздухе после прыжка)   | 0/1                              |
| 20  | g_ground       | one-hot: поверхность земля            | 0/1                              |
| 21  | g_air          | one-hot: поверхность воздух           | 0/1                              |
| 22  | g_water        | one-hot: поверхность вода             | 0/1                              |
| 23  | hp_self        | HP бота                               | hp / MAX_HP                      |
| 24  | arm_self       | броня бота                            | armor / MAX_ARMOR                |
| 25  | hp_opp         | HP врага                              | hp / MAX_HP                      |
| 26  | arm_opp        | броня врага                           | armor / MAX_ARMOR                |

`FEATURE_DIM = 27`.

## Скользящее окно

На вход сети подаётся `WINDOW` последних тиков, склеенных в один вектор:

```
WINDOW = 16
INPUT_DIM = FEATURE_DIM * WINDOW = 432
```

Порядок внутри окна: тик t-WINDOW+1, ..., тик t, каждый — свои 27 признаков.
Если истории меньше WINDOW, самые старые позиции заполняются нулями (padding).

## Выход сети (6 величин, предсказываются дельты)

| idx | имя       | диапазон | смысл                              |
|-----|-----------|----------|------------------------------------|
| 0   | dyaw      | любой    | Δyaw за тик (градусы, raw)         |
| 1   | dpitch    | любой    | Δpitch за тик (градусы, raw)       |
| 2   | fwd       | -1..1    | целевая скорость вперёд            |
| 3   | strafe    | -1..1    | целевая скорость страйф            |
| 4   | attack    | 0..1     | флаг атаки (sigmoid, порог 0.5)    |
| 5   | block     | 0..1     | флаг блока/уклонения (sigmoid)     |

Каналы 0..3 — непрерывные (linear-выход, MSE). Каналы 4..5 — logits,
получают sigmoid при инференсе и BCE при обучении.

`TARGET_DIM = 6`.

## Архитектура сети (умолчание)

```
MLP:
  input  : 432
  hidden1: 256  relu
  hidden2: 128  relu
  hidden3: 64   tanh
  output : 6    linear (кроме attack/block — sigmoid применяется после)
```

Опционально (итерация 2) — LSTM/GRU вместо окна. Формат весов идентичен.
